# Texas Active DAHS & ISS Provider Matcher

基于德州 HHSC 官方最新数据库 (08/14/2026) 打造的全州特需机构智能匹配系统。

## 包含数据
- **1,130 家** 德州官方活跃执照 Provider 机构
- 覆盖全州所有 254 个 County
- 包含 DAHS (传统日照/护理) & ISS (Individualized Skills and Socialization) 项目分类

## 部署说明 (GitHub Pages)
1. 解压本压缩包。
2. 将 `index.html`, `styles.css`, `app.js` 上传至 GitHub 仓库。
3. 进入仓库 **Settings -> Pages** 开启 GitHub Pages 服务即可。
